## 收什么

- **收**：行情与经济数据、官员表态、公司与产品信息、第三方报道、作者自述的持仓与操作。作者自己的算术（如 1502 F17
  用指引倒推前瞻市盈率）收，标「作者计算」，核算术、不核假设
- **不收**：观点、推理、预测。截图上的观点句（如 1502 片尾对 CBRS 的看法）也不收
- 截图里的表**整表转录**（16 张），不只记作者口述提到的那几格；`detail` 写作者在图上标了什么
- `quote` 逐字取自转录稿，`build.py` 校验；`check` 用库内数据（daily_bars、eps_estimates、FRED）核，核不了写「无法核对」，
  不猜

## 文件

- `talk_1500.py` `talk_1501.py` `talk_1502.py`：每期的事实（手写）。`frame` 是精简前全集里的截图文件名
- `build.py`：校验 quote 与截图，生成查看页（截图内嵌）。转录稿从知识库只读取出，要在 backend 目录、带隧道运行
- `template.html`：查看页。按期分页，每条事实带核对状态，截图点开看
- 截图与生成的页面不进仓库（`out/` 已 gitignore）：截图是作者的画面，仓库是公开的

```bash
cd backend && PYTHONPATH=. .venv/bin/python ../docs/research/fact-pilot/build.py <截图根目录>
```

## 做样板时看到的

- **数据主要在截图里**：口述只念表里的几格。1502 耐克季报，口述只说 EPS 0.48（预期 0.44）与毛利率 42.8%（预期 42.4%）
