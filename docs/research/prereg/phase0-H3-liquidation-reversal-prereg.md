## B. 假设（可证伪，symmetric fade）

**当某标的某小时出现极端单向爆仓（级联）时，被强平方向的强制流是非知情的、会过冲，
未来数小时价格朝**被强平的反方向反弹**，风险调整净收益为正。**

- 多头被大量强平 = 强制**卖出** → 价格过冲下跌 → 反弹 → **做多**（买被砸下来的）。
- 空头被大量强平 = 强制**买入** → 价格过冲上涨 → 回落 → **做空**。
- 即 **fade 级联**：交易方向 = 被强平占优的那一方（long 被爆 → 做多）。
- **经济理由**：强平是被动、价格不敏感的强制流，制造临时错位 → 均值回归。加密里机制最干净的 edge 之一。
- 反面（若数据显示级联后**继续同向**）= 知情流/动量，H3 死并记录该反向线索。

## C. 信号定义（精确、可机械计算，全部锁定，跑前不调）

在每个小时 t（有 liq_total_1h 的桶），同时满足即触发：
1. **级联尺度**：`liq_total_1h(t)` 的 30d **时间加权分位 ≥ 0.98`（该标的近 30 天最猛的 2% 小时）。
2. **绝对地板**：`liq_total_1h(t) ≥ $500,000`（滤掉安静期的相对"尖峰"假阳）。
3. **单向占优**：`max(liq_long, liq_short)/liq_total ≥ 0.70`。
4. **交易方向 d** = 被强平占优方：long 被爆占优 → d=long；short 被爆占优 → d=short。
5. **去重叠**：同标的触发间隔 < 12h 只留第一个。
6. 分位严格只用 t 之前数据（无未来函数）。

---

## D. 前向收益 / 交易 PnL

- 进场：t 之后第一根 1h bar 收盘价。出场：进场 +4h（主）；+8h/+12h 仅记录。
- 方向 PnL（净）：`pnl = (ret if d==long else −ret) − COST`，`ret=(P_exit−P_entry)/P_entry`，`COST=0.0014`（往返 14bps）。
- 风险调整：`pnl / atr_pct_1h(t)`（进场时已知，单位一致即可比）——次要。

## F. 基线（关键：把"级联择时"和"方向 mix"分开）

- **随机择时零分布**：保留触发集 S 的方向标签，但把进场时刻换成随机小时 → bootstrap 出均值 PnL 的零分布。
  S 的均值若显著超过它，说明赚的是**级联那一刻的择时**，不是方向 mix 的运气。
- **零基线**：fade 策略是方向性的，真 edge 必须净期望 > 0（绝对赚钱），不只是"比基线好"。

---

## G. 裁决判据（跑前锁死，①必过 + ②③④⑤）

设主 horizon +4h、去重叠后触发集 S：
1. `|S| ≥ 40`（否则"功效不足"，去前向积累，不下结论）。
2. `mean(pnl_S) > 0` 且其 **bootstrap 单边 95% CI 下限 > 0**（绝对净期望为正）。
3. `mean(pnl_S) > 随机择时零分布上限`（级联择时确有增量 edge）。
4. 命中率（pnl>0）`> 50%`。
5. ≥3/5 标的的 mean(pnl) 为正（不被单一标的带飞）。

→ ①②③④⑤全过 = **有戏** → Phase 4 前向确认 → 第一个真 edge。

## G'. 杀掉

- `|S|≥40` 但 ②不过（净期望 ≤0）→ **H3 无 edge**，存档。
- 若 `mean(pnl_S)` 显著为负（级联后继续同向）→ H3 死 + 记"爆仓=知情/动量"反向线索（也许该测动量版）。

## H. 必须控制的混淆

1. 无未来函数：分位/地板只用 t 前数据；前向收益只用 t 后；atr 用进场时已知值。
2. 去重叠 12h（级联常连发，避免同一事件灌成多个样本）。
3. 单一主判据 = 主 horizon +4h + C 的主信号；其余 horizon / 风险调整仅探索，不进裁决（防多重检验）。
4. universe 固定；阈值（0.98 / $500k / 0.70 / 12h / 4h）预注册锁死，**禁止事后调参找显著**。
5. 数据质量：跨所爆仓是估算，噪声大 → SCREEN 结论务必前向确认。
6. regime：~180d 仍偏单一市况。
