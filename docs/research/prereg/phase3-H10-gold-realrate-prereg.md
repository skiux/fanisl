# Phase 3 预注册：H10 — 实际利率变动 → 黄金/白银 反向漂移

> 预注册：判据/信号/切分跑前写定。写定日期：2026-06-14。
> 全新家族（宏观驱动，非 fade/动量/PEAD）。零新 key：FRED 实际利率(DFII10)+ 金银价(已在库)。可 holdout。

---

## A. 假设（可证伪）

**黄金无息，机会成本=实际利率。当 10 年期 TIPS 实际利率在过去约 1 个月下行（上行）时，
未来约 1 个月金价继续上涨（下跌）——即金价对实际利率变动存在滞后/延续，扣成本后净期望为正。**

- 经济理由：实际利率是金价最强宏观驱动之一；若黄金对实际利率变动**未完全即时定价**（滞后反应），
  则 trailing 实际利率变动可预测金价 forward。
- 反面（净≤0 或 holdout 崩）= 黄金已即时定价实际利率，无滞后 edge → KILLED（也是有价值的效率结论）。

---

## B. 信号（精确、机械、锁定，禁止调参）

- 实际利率 = FRED `DFII10`（10年 TIPS），存 scope=global `real_rate_10y`。
- 在每根金/银日线 t：`Δr = real_rate(t) − real_rate(t−30天)`（asof，严格只用 ≤t）。
- 方向 d：Δr < 0 → **long**（利率降→金涨）；Δr > 0 → **short**。sign-only，无幅度阈值。
- 去重叠 30 天（= 主持有，样本不重叠）。进场 = t 之后第一根日线。

---

## C. PnL / horizon

- 出场 = 进场 + **30 天**（主）；+15/+60 仅记录。容差 5 天。
- 净方向 PnL = `(ret if long else −ret) − COST`，COST=0.0010（金银期货/CFD 极流动）。

---

## D. universe / 切分

- 主：XAU/USD；XAG/USD 作确认（注：两者高度相关、且共用同一实际利率信号，非独立检验，⑤ 仅作稳健性参考）。
- In-sample：< 2018-01-01；Holdout：≥ 2018-01-01。判据 in-sample 锁定，holdout 复核 = make-or-break。

---

## E. 裁决判据（锁死；①必过 + ②③④⑤ 在 in-sample）

1. `|S| ≥ 40`。
2. `mean(pnl_S) > 0` 且 bootstrap 单边 95% CI 下限 > 0。
3. `mean(pnl_S) > 随机择时零分布上限`（保留多空配比；防 regime/beta 假阳）。
4. 命中率 > 50%。
5. 两标的（金、银）mean(pnl) 均 > 0（弱判据，因二者相关）。

→ in-sample 全过 且 holdout 净>0 = 候选 → Phase 4 + beta 分解（防"金牛市顺风"伪装）。
→ in-sample 不过 或 holdout 崩 = KILLED（不挪门）。

## F. 防自欺

1. 阈值（30天 Δr / 30天持有 / 2018 切分 / COST）跑前锁死；只测反向一个方向。
2. 时点：Δr 只用 ≤t；进场 t 之后；实际利率为当日已公布值。
3. **regime/beta 风险**（2019-2026 金大牛）：随机择时零分布保留多空配比来防它；若②过，再做 beta 分解
   （策略净 vs 配比加权无条件均值）确认择时超额，照搬 H7 的做法。
4. 单一 regime 倾向由 in-sample/holdout 两段缓解；holdout 是真正裁判。
