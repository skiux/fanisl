## B. 假设（可证伪）

**当某标的的资金费率处于其近期分布的极端低分位（深度为负）时，未来数小时出现均值回归的向上反弹，
其风险调整后前向收益显著高于基线。**

- **方向**：极端负资金费 = 空头向多头付费 = 空头拥挤/情绪偏空 → 预期**轧空式向上反弹** → **做多**。
- **经济理由**：极端负 funding 是结构性失衡（空头拥挤、付费持有空单），有挤压燃料；这是可重复的
  positioning 失衡，不是"读图判断"。属于一个有先验的 setup，正是新范式要找的东西。

## C. 信号定义（精确、可机械计算，无事后自由度）

1. **分位用自算的，不用存的 funding_percentile**：在每个候选时刻 `t`，取该标的 `funding_rate` 在
   `[t-W, t)` 窗口内的**时间加权分位**（用 analytics.py 的 `time_weighted_percentile`，因为序列是
   sample-and-hold 落库的）。**W = 30 天**（预注册锁定）。`t` 之前的数据才参与——**严格无未来函数**。
2. **触发条件**：`funding_rate(t) < 0` **且** 其 30d 时间加权分位 `≤ 15`（即处于近 30 天最低 15%）。
3. **采样时刻**：在 funding 观测点上评估（8h 一次）。
4. **去重叠**：同一标的两个触发间隔 `< 12h` 的，只保留第一个（保证样本近独立，避免自相关灌水）。
5. **次要变体（探索性，不进主判据，仅记录）**：
   - V2：再加 `price 24h 跌幅 > 0`（确认是下跌后的负费，而非横盘）。
   - V3：再加 `OI 在该 24d 窗口下降`（去杠杆）——仅 24d 数据，弱证据。
   - 这些只为观察，**不参与 H1 的 yes/no 裁决**（防多重检验 p-hacking）。

## D. 前向收益度量

- 从触发时刻 `t` 的下一根 1h bar 收盘价进场（避免用 `t` 当根未来信息）。
- **主 horizon = +4h**；次要 +8h、+12h（仅记录）。
- 度量两种：
  - **raw 前向收益** `r = (P(t+h) - P_entry) / P_entry`（做多，正=赚）。
  - **风险调整** `r / ATR%(t)`（用进场时已知的 1h ATR 百分比，归一不同标的/波动）。
- **扣成本**：减去引擎的 taker_fee_bps(5) + slippage_bps(2) 往返 ≈ 14bps，得净收益用于期望判据。

## F. 基线（必须跑，否则"赢一笔"无法解读）

对同一 universe、同一 horizon：
1. **无条件基线**：所有 funding 观测点（不筛分位）的前向收益分布——H1 必须显著优于它。
2. **随机进场**：等量随机时刻做多，bootstrap 出收益分布。
3. **buy & hold**：同期持有的 4h 滚动收益。

## G. 预注册裁决判据（跑之前锁死，全部满足才算"有戏"）

设触发样本（去重叠后）为集合 S，主 horizon +4h，风险调整净收益。

1. **样本量**：`|S| ≥ 40`（5 标的合并、去重叠后）。
   - 若 `< 40` → 裁决 = **"功效不足/暂不可测"**，不下"有/无 edge"结论，转去前向积累更多。
2. **方向与幅度**：S 的**风险调整净收益均值 > 无条件基线均值**，且单边 bootstrap 95% CI 下限 > 基线均值
   （或单边 t 检验 p < 0.05）。
3. **命中率**：S 的正收益占比 > 无条件基线命中率（且 > 50%）。
4. **不被单一标的带飞**：5 个标的里 ≥3 个的均值方向一致为正。
5. **扣成本仍正**：S 的**净**（扣 14bps）期望收益 > 0。
6. （确认阶段）前向 ≥4 周新样本上，符号保持、不崩（小样本不强求显著，但不能反向）。

→ **1–5 全过 = H1"有戏"**，进入 Phase 4 用它做第一个 playbook setup + 上实盘/前向确认。

## I. 必须控制的混淆（quant 命门，预注册即承诺）

1. **无未来函数**：分位只用 `t` 之前数据；前向收益只用 `t` 之后；ATR 用进场时已知值。
2. **重叠/自相关**：去重叠（间隔 ≥12h）；funding 高度自相关，按"事件/episode"计数而非逐点。
3. **多重检验**：**唯一主判据 = 主 horizon +4h + C 的主信号定义**；其余 horizon/变体全是探索性、不进裁决。
4. **universe 固定**：写定就锁，禁止事后挑表现好的标的。
5. **regime 警告**：70 天大体是单一市况——SCREEN 结论的可推广性有限，故必须前向确认。
6. **成本真实**：用引擎同款 fee+slippage，不用无摩擦收益骗自己。
