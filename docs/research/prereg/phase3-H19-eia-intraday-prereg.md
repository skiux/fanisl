# H19 预注册：EIA 库存 surprise → WTI **盘中**漂移（1h 粒度，H18 的粒度续问）

> 预注册日期：2026-07-09。**判据在跑回测前锁死，不挪门。**
> H18（日线粒度，KILLED）的尸检结论：EIA 信息当日消化、发布次日起无漂移，且
> +1d→+5d 无累积——若漂移存在，只可能活在**发布后的几小时内**。本 H 直接测这个边界。
> 与 H18 唯一的本质差异 = 执行粒度（1h vs 日线）；surprise 构造原样复用（干净对照）。

## 假设

EIA 库存 surprise（季节 z，同 H18）在**发布后 30–90 分钟进场、持有数小时**的粒度上，
存在与 surprise 同向的可交易漂移（超预期累库 → short，超预期去库 → long）。

- **经济理由**：即时反应（发布后数分钟）无疑存在但散户抓不到；假设的是反应**不完全**——
  头寸调整（基金再平衡、CTA 信号更新）在发布后数小时内持续。这是 underreaction 的
  盘中版本，H18 只能证明它活不过次日，管不到当日。

  `h18.build_events` + `h18.seasonal_z`（ISO 周 ±1 × 过去 5 自然年，≥5 样本，|z|≥1 触发，
  阈值/参数一字不改）。季节窗用全历史（1982+），事件样本从价格可及处（2008+）开始。

  与 FRED 日线 `price` 分开存（防混合密度伪象）。

## 发布时点与假期调整（盘中版的命根子，锁定）

- 基准发布时刻：period（周五）+5 天 = 次周三 10:30 ET（同 H18，zoneinfo 换算）。
- **假期顺延（H18 不需要、H19 必须）**：日线版进场在发布次日结算，自带 ≥1 天缓冲；
  盘中版进场在发布后 30–90 分钟，若实际发布顺延周四而合成戳仍是周三，就会**在信号
  发布前按信号进场 = 真未来函数**。锁定规则：**美联邦假日（observed）落在
  [period_end−4 天, 合成周三] 区间内（报告周工作日或发布周一~周三）→ 发布时刻改为
  周四 11:00 ET**；若该周四本身是假日 → 周五 11:00 ET。
  - 实证锚点：2026-07-03 period（7/4 observed 周五落在报告周）实际发布 = 2026-07-09
    周四（今日观察到 API 更新时刻），规则判定一致。
  - 已知残余：若 EIA 在此类周仍按周三发布（规则假阳性），进场晚一天 = 信号稀释，
    **偏保守方向**，可接受；规则假阴性（>1 天的极端顺延）罕见，照实记。
- 假期表：2007–2027 美联邦假日（元旦/MLK/总统日/阵亡将士/六月节 2021+/独立日/劳动节/
  哥伦布日/退伍军人日/感恩节/圣诞，周六 observed 前移周五、周日后移周一），纯函数可单测。

## 执行（锁定）

- **进场**：调整后发布时刻之后**严格第一根 H1 收盘**（正常周 = 周三 15:00Z 夏令 /
  16:00Z 冬令，发布后 30 分钟）。进场 bar 收盘距发布 > 3 小时（数据洞）→ 丢弃该事件。
- **出场**：进场 bar + h 根 H1（行索引步进 = 交易小时）。**主 h = +8 交易小时**
  （覆盖发布日剩余时段，H18 已证活不过次日）；h = 4、24 只作探索报告，不参与裁决。
- **成本**：往返 10bps（WTI CFD 点差 ~3-5bps，取保守），与 H8/H18 一致。
- **方向**：z > 0 → short；z < 0 → long。|z| ≥ 1.0（同 H18，不调参）。
- 周度事件、持有 ≤24h，无重叠，不需去重。

## 多重检验声明

单一主 horizon（+8 交易小时）、单一阈值（|z|≥1，继承 H18 不改）、单一标的。
h=4/24 与全事件符号交易只作探索报告，不据其 claim；要追必须另立 H。
