## 结构

- **事实**：作者引用的数据、事件、第三方表述、自己的复盘。带 `check`：用库内数据核对的结果（一致 / 大致一致 /
  部分可核 / 不一致 / 无法核对）与明细
- **推理**：作者从事实走到判断的一步。`from` 列出依据，`link` 是作者的连接语原文（「所以」「因为」「唯一的解释是」）
- **结论**：价格判断、立场、操作。`units` 对应现有 claim 单元，页面上显示它们的等级与评分——验证保留为背景信号
- **方法**：可复用的推理模板，`nodes` 是已有的跨期节点

规则：
1. `quote` 与 `link` 逐字在原文里（`build.py` 校验，不过就不生成）
2. **只连作者明说的连接**。作者没连到结论上的推理就让它悬着，不替作者补逻辑
3. `text` 是我方的简述，只作标签；判断以 `quote` 为准
4. 事实按作者说话时点核对，不按发布日（c126 发布于 9-20，录于 8 月下旬）
