# Phase 3 预注册：H9 — 财报后漂移 PEAD（美股，公告反应当 surprise 代理）

> 预注册：判据/信号/切分跑前写定。写定日期：2026-06-14。
> 数据全部无 key / 抓取/原始：Yahoo 复权日线（2010+）+ SEC EDGAR 10-Q/10-K 备案日（深、精确、PIT 干净）。
> **不需一致预期**——用公告窗口相对市场的异常收益当 surprise 代理（标准 PEAD 变体），绕开深度 consensus 卡点。

---

## A. 假设（可证伪，最稳健的股票异象之一）

**财报公告后，价格沿"公告即时反应"的方向继续漂移数周（PEAD）：公告窗口相对 SPY 异常收益为正的股票，
未来 ~40 交易日相对 SPY 继续跑赢；为负的继续跑输。市场调整、扣成本后净期望为正。**

- 经济理由：信息缓慢被定价（注意力有限、机构调仓滞后）。PEAD 是文献中最稳健、跨几十年的异象之一。
- 做法 = 市场中性对（多/空该股 + 反向 SPY），隔离个股 PEAD、剔除大盘 beta。
- 反面（净≤0 或 holdout 崩）= 这批大盘股 + 本设定下 PEAD 不可利用 → KILLED。

---

## B. 信号（精确、机械、锁定，**禁止调参**）

- 事件 = 每个 10-Q/10-K 备案日 t（EDGAR，ts=备案日 21:00 UTC = 美股收盘后）。
- **surprise 代理** = 公告窗口市场调整 CAR：t（含）往前 **5 个交易日**的 Σ(个股日收益 − SPY 日收益)。
  仅用 ≤t 数据（无未来函数）。注：备案日 ≈ 盈利新闻稿（通常前 0–数日），5 日窗口意在覆盖该反应——
  这是已知近似，holdout 检验其稳健性；若有戏再用 8-K Item 2.02 精确化。
- 方向 d：CAR > 0 → long；< 0 → short。
- 去重叠 25 天（季报间隔 ~63 交易日，漂移 40 天 < 一季，几无重叠；防 10-Q/10-K 紧邻重复）。

---

## C. PnL / horizon（市场中性）

- 进场 = t 之后第一根日线（次交易日，个股与 SPY 同日）。
- 出场 = 进场 + **40 交易日**（主，~2 月，经典 PEAD 窗）；+20/+60 仅记录。
- 净 PnL = `d · [(个股_exit/个股_entry−1) − (SPY_exit/SPY_entry−1)] − COST`，**COST=0.0015**（对子两腿，~15bps）。

---

## D. universe / 切分

- universe：NVDA/AAPL/TSLA/MSFT/META/AMZN/GOOGL/COIN/MSTR/MU（深历史大盘股），SPY 作基准。
- **In-sample**：事件 < 2019-01-01；**Holdout**：≥ 2019-01-01。判据 in-sample 锁定，holdout 复核 = make-or-break。

---

## E. 裁决判据（锁死；①必过 + ②③④⑤ 在 in-sample）

1. `|S| ≥ 40`。
2. `mean(pnl_S) > 0` 且 bootstrap 单边 95% CI 下限 > 0。
3. `mean(pnl_S) > 随机择时零分布上限`（保留多空配比）。
4. 命中率 > 50%。
5. ≥ 60% 标的 mean(pnl) 为正。

→ in-sample ①-⑤ 全过 **且 holdout 净>0** = 第一个跨 regime 站住的候选 → Phase 4。
→ in-sample 不过 或 holdout 崩 = KILLED（不挪判据）。

## F. 防自欺

1. 阈值（5 日 surprise 窗 / 40 日漂移 / COST / 2019 切分）跑前锁死；只测 PEAD 顺势一个方向。
2. 时点：surprise 只用 ≤t；备案后次日进场；前向只用进场之后。
3. 复权价（Yahoo adjclose）杜绝拆股/分红假跳。市场调整剔除 beta。
4. 备案日 ≈ 新闻稿的近似已声明；holdout 是真正裁判。
