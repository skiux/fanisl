# Phase 3 预注册：H17 — 趋势×定位闸门（上升趋势中的负资金费 → 逼空/carry 做多）

> 预注册：判据/信号/切分在跑前写定，事后不改。写定日期：2026-07-08。
> 来由有二：(1) H4 之后一直标记的"组合/条件化"方向；(2) 2026-06 下旬的实盘分析里"趋势×定位"框架
> 反复正确区分了该买与该躲的标的（ZEC 顺势+空头拥挤 vs 下跌趋势里的同样信号）。本 H 把它变成可证伪命题。

---

## A. 与已死 H1 的区别（防"换皮重测"）

H1（KILLED）：**无条件** fade 资金费极端（分位 ≤0.15 → 做多），均值回归论，+4h，主流 5 币，~70d 单 regime。
H17 四点本质不同：
1. **条件化**：趋势闸门（价 > 200 日线）是信号的一半——同一个负资金费，上升趋势=逼空燃料，下跌趋势=知情空头；
2. **机制不同**：不是"极端会回归"，是**顺势 + 空头付费**（carry 收入 + 空头回补的不对称）；
3. **horizon**：+3 天（H6/H7 的成本地板教训：4h 级信号全被 14bps 吃掉）；
4. **数据**：资金费 **~5 年日线**（Coinalyze，2021-07→今）× 23 标的，多 regime + 真 holdout（H1 只有 70 天）。

## B. 假设（可证伪）

**当某永续标的处于上升趋势（现货价 > 200 日均线）且资金费为负（空头拥挤、空头在付费）时，
未来 ~3 天做多的净期望为正（扣 14bps）；同一负资金费信号在下跌趋势（价 < 200 日线）中不成立。**

- 反面（主格不过 或 holdout 崩 或 与趋势内随机择时无差）= 趋势×资金费的条件组合也无增量 edge → KILLED。

## C. 信号（精确、机械、锁定，禁止调参）

- universe：23 个 USDT 永续（5 主流 + 18 中小盘，即库内 price+funding 全集）。
- 数据：`funding_rate_1d`（日线收盘资金费，ts=桶收盘）+ `price`（重采样为逐日最后收盘）。
- 在每个 funding_rate_1d 时点 t：
  1. **趋势**：SMA200 = 严格 ≤t 的最近 200 个日收盘均值（≥150 个才算，否则跳过）；up = price_asof(t) > SMA200。
  2. **定位**：f = 该日收盘资金费；neg = f < 0（符号判据，不设幅度阈值，防扫参）。
  3. **主格 A = up ∧ neg → 做多**。B(down∧neg)/C(up∧pos)/D(down∧pos) 仅记录作对照（探索，不进裁决）。
  4. 去重叠：同标的 3 天（= 主持有）。
- 进场 = t 之后第一个日收盘；出场 = 进场后第 3 个日收盘（主），第 1/7 个仅记录。净 PnL = ret − 0.0014。

## D. 切分

- **In-sample**：t < 2025-01-01（≈2022-12→2024-12，含 2022 熊尾、2023 震荡、2024 牛）。
- **Holdout**：t ≥ 2025-01-01（≈1.5 年）。判据在 in-sample 锁定，holdout 复核 = make-or-break。

## E. 裁决判据（锁死；全在 in-sample 主格 A 上，⑥为 holdout）

1. `|A| ≥ 40`。
2. `mean(pnl_A) > 0` 且 bootstrap 单边 95% CI 下限 > 0。
3. **超"趋势内随机择时"零分布上限**：零分布从**同样满足 up（价>SMA200）的全部日 bar** 抽 |A| 个 3 日多头净收益，
   取其均值分布的 97.5 分位。——直接检验资金费在趋势内的**增量**（H7 的 beta 教训焊进判据，杜绝"只是趋势 beta"）。
4. 命中率 > 50%。
5. ≥60% 的标的（触发 ≥3 次者）mean > 0。
6. **holdout：|A|≥20 且 mean > 0**。

→ ①-⑥全过 = 首个"条件化"PASS → Phase 4 前向 OOS。
→ 否则 KILLED。探索记录（不进裁决）：A vs B（闸门价值）、A vs C（资金费增量）、各 cell 均值。

## F. 防自欺

1. 阈值（SMA200/f<0/3d/14bps/2025-01 切分）跑前锁死；主格只有 A 一个，方向只有做多一个。
2. 时点：SMA/资金费严格 ≤t；日线收盘按**收盘时刻**打戳（源头写对，不重蹈 bar 指标污染）；进场 t 之后。
3. ③ 用趋势条件化零分布（不是无条件），从判据层面排除趋势 beta 假阳。
4. universe = 库内全集（非挑选）；survivorship（现存币）作 SCREEN 声明，前向 OOS 无此偏。
