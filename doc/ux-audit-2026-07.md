# Fanisl UX Audit Report（2026-07-17）

> 审计对象：现有前端全部页面（对话页除外，仅涉及其导航地位）。
> 方法：逐页阅读实现（Tailwind 类即排版事实），对照 `frontend/DESIGN.md` v1 与
> `doc/design-philosophy.md` 逐条核查。本报告只诊断，不改代码。
> 引用格式 `文件:行` 均可在源码中核对。

---

## 0. 总判断

现状是**两个时代的 UI 共存**：知识页（2536a87 重设计后）已经是"阅读优先研究工作台"
的正确形态，其余页面仍是数据平台时期的产物——六个分类页是纯数据库视图，交易评测页
是"评测数据 + 操作台"的混合体，且把已正式关闭的酌情实验放在视觉 C 位。产品最有
价值的两张表（setup 计分卡、单笔叙事详情）都存在，但一个藏在账户切换器后面，
一个只能从表格行进入。最严重的单项问题不是布局，是**静默吞错导致空态说谎**——
后端不可用时，所有页面显示"暂无数据/采集后出现"，这在一个以诚实为身份的产品里
是第一优先级缺陷。

## 2. 逐页审计

### 2.1 数据总览（DataExplorer.tsx）

**本质**：`/metrics/catalog` + `/metrics/available` 两个端点的合并渲染——指标名、
样本数、跨度、末值的行清单 + 选中画图。这是带图表的 coverage 浏览器，即数据库
管理视图。副标题自己承认了："所有已采集/回填的指标"。

**价值判断**：作为**证据基底的检验仪器**（查覆盖、看序列形状、核对回填）有真实价值，
研究时会用。错的是定位与排位：它叫"总览"却不综述任何东西，且占据导航第二位。
哲学定位里它是"仪表墙，被引用时是证人"，不是前门。

**层级错误**：KPI 行（[DataExplorer.tsx:236-243](frontend/src/market/pages/DataExplorer.tsx#L236)）
把"最新值"与"样本/跨度/起始"六格同权并列——市场事实与数据库行数元数据在同一层级。
读者该注意什么，界面没有回答。

**视觉重点错误**：全页最强的彩色元素是 emerald 渐变面积图
（[DataExplorer.tsx:253-284](frontend/src/market/pages/DataExplorer.tsx#L253)）——
任意指标一律绿色渐变填充，强调色作装饰漆用；选中行 `bg-emerald-50/60`
（[DataExplorer.tsx:202](frontend/src/market/pages/DataExplorer.tsx#L202)）把判决色
用作选中态。

**DESIGN.md 违规**：R1（"最新"值无 as-of，`Freshness` 组件存在却未使用）；
§8（面积渐变填充明令禁止；主序列应 zinc-700 非 accent）；R4（accent 作选中态）；
§14（recharts 动画未关）；R11（`catch(() => setCoverage([]))`
[DataExplorer.tsx:73](frontend/src/market/pages/DataExplorer.tsx#L73)——API 失败
显示"该标的暂无数据"，空态说谎）。

### 2.2 六个分类页（Categories.tsx，技术/衍生品/盘口/链上/情绪/宏观）

**本质**：与数据总览完全相同的数据，按 `category` 列过滤后渲染成卡片网格。
六个顶级导航位 = 一个 SQL WHERE 子句的六种取值。这是审计中最纯粹的"展示数据库"。

**价值判断**：接近零。卡片**不可点击**（MetricCard 无 onClick，
[Categories.tsx:104-122](frontend/src/market/pages/Categories.tsx#L104)）——看到
异常也无处可去，是死胡同；不回答任何问题（"技术面如何？"不等于 20 个末值卡片）；
后端明明有语义化阈值标签（`snapshot/builder.py` 的 TimeframeView），界面却只给裸数。
与数据总览完全冗余且交互更弱（无时间范围、无大图）。六个导航位的代价换来的是
DataExplorer 的一个筛选按钮已经提供的东西。

**层级错误**：卡片内 17px 粗体 mono 末值是最大元素，但它没有语境（无变化量、
无 as-of、无阈值语义）；`samples.toLocaleString()` 点数（数据库元数据）与市场值
并列同格；排序按指标名字母序——任意序。

**视觉重点错误**：一屏 20-40 张卡片、每张一个 17px 焦点 = N 个重心 = 零重心
（违反 R5）。Sparkline 按窗口首末值染红绿
（[ui.tsx:141-142](frontend/src/market/ui.tsx#L141)）——365 天窗口的"方向"没有语义，
纯装饰性红绿，直接违反 R4。

**DESIGN.md 违规**：R4、R5、R1（末值无 as-of）；R7（`text-[10px]` 两处，
[Categories.tsx:110](frontend/src/market/pages/Categories.tsx#L110)、
[118](frontend/src/market/pages/Categories.tsx#L118)——低于 11px 下限）；
§5.2（三/四列等分卡片网格被明令禁止）；§5.1（卡片 hover 阴影，
[Categories.tsx:106](frontend/src/market/pages/Categories.tsx#L106)，平面内容禁止阴影）；
R11（`catch → setCards([])` 空态说谎，[Categories.tsx:63-64](frontend/src/market/pages/Categories.tsx#L63)）。

### 2.3 交易评测（Trading.tsx）

**本质**：混合体。计分卡/持仓/权益曲线/交易记录是真评测数据；但页头一排操作按钮
（让 Claude 评估 / 自主扫描 / 强制开关 / 手动推进一拍 / 探测一轮）是**操作台**，
其中"推进一拍"是引擎调试动作（worker_trader 的活儿），"让 Claude 评估/自主扫描/强制"
属于已正式关闭的酌情实验（research-capstone：该实验不再单独回答；scan 默认关）。

**价值判断**：中。权益曲线与持仓表在跟踪 setup/实盘账户时有真价值。但存在
**双重价值倒置**：①黑色主按钮（全页最强 CTA，
[Trading.tsx:146-149](frontend/src/market/pages/Trading.tsx#L146)）给了废弃实验；
②评测台重定位后的核心产出——**按 setup 评 edge 的计分卡**——只有切到 setups/live
账户才渲染（[Trading.tsx:227-240](frontend/src/market/pages/Trading.tsx#L227)），
而默认账户是 main（已关实验的账户）。最重要的表藏在开关后面，最不重要的按钮
放在页头。

**层级错误**：8 格 KPI 行把纸面账户的模拟记账（权益/可用现金/占用保证金）与
评测结论（期望 R、盈利因子）同权并列；更有信息量的"出场效率/管理贡献/拒绝力/校准"
反而降格为 KPI 行下方 11px 灰色脚注
（[Trading.tsx:197-224](frontend/src/market/pages/Trading.tsx#L197)）。层级与
"这页要回答什么"（setup 有没有 edge）无关，与"后端返回什么结构"一致——数据库
思维的残留。

**视觉重点错误**：强制开关开启时变成全页唯一实心绿块
（[Trading.tsx:155-157](frontend/src/market/pages/Trading.tsx#L155)）——最高视觉
权重给了实验配置旗标；权益曲线无论盈亏一律绿线绿渐变
（[Trading.tsx:306-324](frontend/src/market/pages/Trading.tsx#L306)），回撤中的
账户呈现为"上涨色"，违反诚实密度。

**DESIGN.md 违规**：R4（多处：Panel 标题装饰性绿图标
[Trading.tsx:245](frontend/src/market/pages/Trading.tsx#L245)；做多=绿 Badge 把
方向当判决染色）；R2（"胜率"格无 n，n 在另一格"持仓/已平"里，弱违反）；
R1（KPI 无 as-of）；§14（equity/detail 图动画未关 + 15 秒轮询 = 反复重绘动画）；
R13（界面出现引擎操作按钮，违反"界面作证，机器运转"；探测/推进作为调试入口
应降格或移出）；R11（[Trading.tsx:64](frontend/src/market/pages/Trading.tsx#L64)
静默吞错）；R15（页头副标题塞满行话"纸面永续 · 多账户对照 · setup=规则触发+…"，
是备忘不是界面文案；账户标签 'A · 自然' 'B · 强制' 是实验内部代号）。

### 2.4 Setup 计分卡（SetupsPanel.tsx）——单独评，因为它是核心

**价值判断**：高。先验 vs live 同单位对照、信号漏斗、否决力——这正是重定位后
产品要回答的问题。**多处是全站合规范例**：比率带样本量（`N · 命中率`、
`否决力 x% (a/b)`）、诚实脚注（"N 小时结论别当真——攒到 ≥30 笔再看期望"、
"candidate 不代表可信 edge"，[SetupsPanel.tsx:124-128](frontend/src/market/pages/SetupsPanel.tsx#L124)）、
CI 随值展示。这张表按 DESIGN.md §12 的标准接近满分。

**问题**：位置（见 2.3 价值倒置）；九列表格在 1400px 容器里接近极限，先验列与
live 列的对照关系（这张表的灵魂）靠列顺序暗示而非视觉分组；`text-[11.5px]`
阶梯外字号数处。

### 2.5 实盘录入（ManualPanel.tsx）

**价值判断**：高——它是全站唯一被 DESIGN.md R13 允许的写操作，且实现基本得体：
label 在输入框上方、必填标注、录入后清空重填。基本合规。

**小问题**：作为"仪式性登记"（哲学§3 原则五），它现在是 8 列一行的紧凑表单，
登记的郑重感不足——属于重设计时的方向调整，不算违规；"风险% / 杠杆"一个 label
两个输入框，语义含混（[ManualPanel.tsx:73-79](frontend/src/market/pages/ManualPanel.tsx#L73)）。

### 2.6 交易详情（TradeDetail.tsx）

**价值判断**：高。"决策依据 → 过程 → 结果 → 复盘"的叙事结构是**结论—口径—证据
文法的先驱**：结果面板里 realized_r/planned_r、反事实基准、bh 配对基准、管理贡献
并列——这是证据纪律做进 UI 的最好例子。

**层级小错**：右栏把"复盘（结论层）"与"委托记录（流水账）"同权堆叠；页头一行
塞下返回/编号/标的/方向/状态/setup/撤单/结果速览八种东西，无主次。

**DESIGN.md 违规**：R7（`text-[10.5px]` [TradeDetail.tsx:258](frontend/src/market/pages/TradeDetail.tsx#L258)、
图表标注 fontSize 10 [154-159](frontend/src/market/pages/TradeDetail.tsx#L154)——
低于 11px 下限）；R12（引文文法分裂：thesis 用灰底圆角块
[TradeDetail.tsx:185](frontend/src/market/pages/TradeDetail.tsx#L185)，而知识页
quote 用左竖线——同一语义"凭什么"两套排版，全站应统一为左竖线式）；
§14（图表动画未关，未平仓时 15s 轮询反复动画）；R4（浮动盈亏图恒绿渐变，
不随正负）。

### 2.7 知识（Knowledge.tsx）

**价值判断**：高，方向标杆——DESIGN.md 的三行文法就是从它提炼的。按月分组、
单栏文档流、判决徽标寄生结论行、含糊率与 p 值入侧栏、诚实脚注（"样本仍小，
仅供跟踪"）都对。

**残留问题（对标 DESIGN.md 逐条）**：

1. **R3 只做了一半**：评分徽标 hover 有口径（title 属性），**click 无下文**——
   评分详情（冻结口径全文 + 证据图）不存在；这是"证据一跳"承诺的最后一环。
2. **证据链两端断点**：下游 `ref_price` 基准价不链接到价格序列（K4 的 daily_bars
   就在库里）；上游 locator（`12:34` 时间点）是死文本，不能跳转到转录对应段落。
3. **xl 以下联赛表整体消失**（`hidden xl:block`
   [Knowledge.tsx:291](frontend/src/market/pages/Knowledge.tsx#L291)）——侧栏内容
   无降级呈现，验证层在窄屏上不存在。
4. R7：13.5/15.5/12.5/11.5/10.5px 等阶梯外字号贯穿全页（DESIGN.md 定稿在其后，
   属迁移项）。
5. R11：`catch(() => {})` 静默吞错，与全站同病。

## 3. 跨页系统性问题（按修复价值排序）

**S1 · 空态说谎（最高优先级，诚实性缺陷）**
全站取数一律 `catch(() => 空数组)`，API 失败与真无数据渲染同一个空态
（"暂无数据 / 采集后出现"）。以诚实为身份的产品，界面在系统故障时撒谎。
违反 R11（error 态缺失）。同根问题：stale 态缺失——`Freshness` 组件写好了
（[ui.tsx:233](frontend/src/market/ui.tsx#L233)）但无页面使用。

**S2 · 导航层级倒置（IA 缺陷）**
[App.tsx:24-30](frontend/src/App.tsx#L24)：10 个平铺标签，对话第一、知识最后、
六个 WHERE 子句占 60% 导航位。核心资产排位最末。哲学§5 已给出四空间方案，
此处仅记录现状证据。

**S3 · 价值倒置（评测台内部）**
已关闭实验的操作按钮占页头 C 位与最强 CTA；核心 setup 计分卡藏在账户切换器
默认值之后。见 2.3。

**S4 · 强调色当装饰漆**
emerald 出现在：任意指标的渐变面积图、选中态底色、Panel 标题图标、做多 Badge、
恒绿权益曲线、sparkline 涨色。判决色的语义被稀释殆尽——当一切都是绿的，
命中的 ✓ 就不再醒目。违反 R4/§8。

**S5 · 时间纪律未进界面**
PIT 是后端第一戒律，但界面上：KPI 无 as-of、卡片末值无 as-of、图表无"截至"
标注（R1 全站性违反）。数据新鲜度（collector 15min 节奏）在 UI 上不可见。

**S6 · 字号失控**
实测存在 10/10.5/11/11.5/12/12.5/13/13.5/14/14.5/15/15.5/17/23/26px 连续体，
其中 10/10.5px 低于可读下限（R7）。另一极：PageShell 页面标题仅 15px
（[ui.tsx:38](frontend/src/market/ui.tsx#L38)）——数据页的页面标题比知识单元的
结论行还小，页级层级塌陷。

**S7 · 图表动画未关**
全站 recharts 无一处 `isAnimationActive={false}`，叠加 15s/30s/60s 轮询 =
数据静默刷新时图表反复播放入场动画。违反 §8/§14"静默替换"。

**S8 · 引文文法分裂**
"凭什么"的排版有两套：知识页左竖线引文块 vs 交易详情灰底圆角块。R12 要求
同一语义同一形态。

**S9 · 容器与阴影残留**
Panel 自带阴影（[ui.tsx:13](frontend/src/market/ui.tsx#L13)）、卡片 hover 阴影、
SegTabs 选中阴影——§5.1 规定阴影仅属 Overlay。KpiRow 虽用分隔线避开了"卡片堆叠"，
但 8 格等权大数字仍是 KPI 墙语义（§5.2/§17），且无主次。

**S10 · Badge 文字 10px**（[ui.tsx:247](frontend/src/market/ui.tsx#L247)），
低于下限，全站 Badge 受累。

## 4. 负空间审计（缺什么，与"有什么"同等重要）

1. **没有前门**：产品打开落在对话页；"自上次打开以来发生了什么"（今日/增量）
   无处可看——K4 的评分器每天产出新判决，用户只能自己翻。
2. **研究档案不在产品里**：23 个裁决、capstone、预注册——项目最独特的纪律资产
   只存在于 doc/ 目录，界面上没有任何入口。"负结果被体面陈列"尚未发生。
3. **知识只有时间一个入口**：按主题/标的/信源枢纽浏览不存在（标签已入库 52 个，
   K3 完成），检索不存在。四个万能连接键只实现了"信源筛选"一个。
4. **claim 证据图不存在**：daily_bars + ref_price + eval_ladder 数据齐备，
   "基准价→评估窗→判决点叠加价格路径"（§8 判决叠加）一张图都没有——这是
   验证层最有说服力的呈现方式。
5. **全局搜索不存在**（⌘K 已在 DESIGN.md §15 冻结键位）。

## 5. 结论

- **真正该消失的**：六个分类页（并回数据总览的筛选维度，或升级为回答问题的
  语义视图——但那是另一次设计）。
- **真正该降级的**：交易评测页头的酌情实验操作组；数据总览在导航中的排位。
- **真正该升格的**：setup 计分卡（评测空间的头版）、交易详情的叙事结构
  （推广为全站文法）、知识页（前门方向）。
- **动工前必须修的**：S1 空态说谎——它不是视觉问题，是产品品格问题。

修复价值排序：S1 → S2/S3（IA 与价值倒置）→ 第 4 节缺失面（今日/检索/证据图）
→ S4/S5（色彩与时间纪律）→ S6-S10（机械清理，随重构顺带完成）。
