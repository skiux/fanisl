## A. 为什么是这个 H（不再单因子 folklore）

H1（funding 极端反转）、H3（爆仓级联反转）**两个单因子 folklore 都高功效负结果**。
H3 已证明：级联**整体**不反转，反而轻微继续同向（动量），但顺势毛收益扣成本只剩 ~+0.0004，
不可利用。结论：**单因子不行**。下一步刻意做"组合/条件化"。

H4 引入**第二个独立信号 OI（持仓量）**，把 H3 的级联触发集按 ΔOI 一分为二，验证一个**有机制先验**的子集是否藏着 edge：

- **诚实声明（防 p-hack）**：H4 不是"把 H3 同一份数据翻方向找显著"。它引入了 H3 没用到的新数据维度（OI），
  且阈值在跑前锁死、只测**一个**先验方向。OI 升/降两子集的对照仅作内部一致性校验，不进主裁决。
- 因 in-sample 子集化会缩样本，**主裁决结论一律标"暂定（SCREEN）"，真确认靠前向样本外**。

## C. 机制先验（跑前锁死，单一主方向）

级联（强制平仓潮）那一刻的 **ΔOI 符号**区分两种世界：

- **OI 下降（去杠杆 / flush）**：持仓被强平出清、未被新仓替补 → 强制流是机械的、会过冲 →
  价格朝被爆的反方向**反弹（fade 成立）**。这是经典"插针后回归"。
- **OI 上升（新仓涌入）**：有人在级联方向**主动加仓**（知情/动量）→ 价格倾向**继续同向**。

**H4 主假设：级联 + OI 去杠杆 子集，fade（被爆方向的反向）净期望为正。**

---

## D. 信号定义（精确、机械、全部锁定）

触发先沿用 H3 的级联定义（**不调**）：在每个有 liq_total_1h 的小时 t：
1. `liq_total_1h(t)` 的 30d 时间加权分位 ≥ 0.98；
2. `liq_total_1h(t) ≥ $500,000`；
3. `max(liq_long, liq_short)/liq_total ≥ 0.70`，被爆占优方记为 side；
4. 去重叠：同标的触发间隔 < 12h 留第一个。

在此之上加 OI 条件（**新增、锁定**）：
5. `oi_chg(t) = (OI_asof(t) − OI_asof(t−3h)) / OI_asof(t−3h)`，**严格只用 ≤ t 的 OI**（无未来函数）。
   - OI 在 t−3h 或 t 处缺值（容差 90min 取不到）→ 该触发剔除（不计入任何子集）。
6. **去杠杆子集 DELEV** = `oi_chg(t) < 0`；**加仓子集 RELEV** = `oi_chg(t) > 0`。
   - 阈值就是符号 0，不引入可调幅度阈值（防 p-hack）；幅度分桶仅作探索，不进裁决。
7. **交易方向 d = fade = 被爆占优方**（long 被爆 → 做多）。与 H3 同。

## F. 基线

- **随机择时零分布**：保留 DELEV 子集的方向 mix，随机择时 bootstrap 均值零分布（复用 H3 的 `_mixed_null_upper`）。
- **零基线**：方向性策略，真 edge 必须净期望 > 0。
- **内部一致性校验（非主裁决）**：若机制为真，应见 DELEV 子集 fade>0 且 RELEV 子集 fade<0（即 RELEV 顺势）。
  这两者方向相反才支持"OI 在区分两种世界"，否则即便 DELEV 数字好看也存疑。

## G. 裁决判据（跑前锁死；①必过 + ②③④⑤；全在 DELEV 子集上）

设主 horizon +4h、去重叠 + OI 去杠杆条件后的触发集 S=DELEV：
1. `|S| ≥ 40`（否则功效不足，去前向积累，不下结论）。
2. `mean(pnl_S) > 0` 且 bootstrap 单边 95% CI 下限 > 0。
3. `mean(pnl_S) > 随机择时零分布上限`。
4. 命中率 > 50%。
5. ≥3/5 标的 mean(pnl) 为正（子集化后样本少，仍保留以防单标的带飞；不达标即 FAIL）。

→ ①②③④⑤全过 = **有戏** → Phase 4 前向确认。

## G'. 杀掉

- `|S|≥40` 但 ②不过 → H4 主假设无 edge，存档；记 DELEV/RELEV 对照观察作探索线索（追则另立 H + 样本外）。
- `|S|<40` → 功效不足，标"待前向积累"，**不在子集上反复换阈值找显著**。
