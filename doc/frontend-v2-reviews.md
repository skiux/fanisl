# Frontend V2 — 逐页 Design Review

## 第二轮（2026-07-17 下午）：证据链闭环

首轮批评成立：交付的是 IA 骨架与合规清理，辨识度体验全部被"待后端"推迟——而后端
本就未完工，读端点应随产品建。第二轮补齐（后端 6 个只读端点 + 前端 5 个面）：

- **单元详情页**（`#/knowledge/unit/:id`，旗舰面）：三问一页闭环——出处（quote+locator+
  原视频）、口径（冻结 ScoringSpec 全文：method/基准/阶梯/success_def）、结果（评分明细：
  基准价/标的收益/基准收益/评估价全部机械依据）；**生命线**（发布●→评估时点→判决色）；
  **证据图**（daily_bars 价格路径 + 发布虚线 + 基准/目标线 + 判决色评估线，DESIGN.md §8
  判决叠加首次落地）。实测单元 #213（SOX 相对判断，07-08 ✓）。
- **知识库五入口**：时间流 / 判断 / 方法 / 认知（跨内容浏览，来源行可跳内容）/ 标签枢纽
  （52 标签按用量排序，按 kind 细分计数）。知识库第一次成为"库"而非内容列表。
- **今日头版=到期评分流**：60 个判决按日分组（判决是每天的新闻），点击直达单元详情。
- **研究档案陈列**：capstone/裁决日志/重定位/知识引擎设计四份文档产品内只读渲染
  （与 doc/ 同源），"负结果体面陈列"落地。
- **⌘K 对象寻址**：导航/信源/标签/内容/指标/单元全文（后端 ILIKE），Overlay 是全站
  唯一阴影层。实测"黄金"同时命中内容与单元。
- 验证：tsc/build 通过；隔离环境（uvicorn:8010 + vite:5174）逐页截图，控制台零错误；
  后端 test_knowledge 6 passed。
- 遗留：K5/K6 面（节点/共识冲突）、locator 精确锚点、ref_price→市场数据链
  （判定为不再必要，见 PRODUCT.md §4）。
- 注意：**8000 端口的 API 进程需重启**才有新端点（当前 5173 指向的是旧进程）。

## 全局（外壳 + 地基）

- 导航 5 项（今日/知识库/市场数据/研究/对话），默认落点今日；hash 路由给每个对象稳定
  地址（audit S2 执行）。✅
- 四态取数（useQuery + QueryGate）：error 与 empty 严格区分——后端 404 显示
  "取数失败：trade 404 · 重试"，不再冒充空数据（audit S1 执行，已实测）。✅
- Token 落地：字号八级阶梯进 tailwind.config；机械扫描 0 个阶梯外字号、0 处越权彩色
  （market/、App、lib 范围）。✅
- 遗留：⌘K 全局搜索未实现（键位冻结）；对话区组件（ChatView/Sidebar/PriceTicker）
  本轮未迁移，其内部字号沿用 Tailwind 默认映射（已随 config 变化自动归位大半）。

## 今日（新建）

- 视觉层级：24px 标题唯一重心 → 元数据行（带"本页截至"）→ 按日分组的增量条目。✅
- 阅读体验：Ledger 双栏，主栏内容流，侧栏战绩快照+系统脉搏；条目一跳进阅读页。✅
- 信息密度：知识层疏排；侧栏 12px 注脚密度。✅
- 哲学符合：核心是"界面作证"——系统脉搏如实显示采集器已 33 天未跑（amber stale
  标注），空态指向 backfill_transcripts。灰是主角。✅
- 遗留（如实标注在页脚）："新到期评分流"与"知识状态变化流"待后端端点；当前主栏只有
  内容增量一种事件。
