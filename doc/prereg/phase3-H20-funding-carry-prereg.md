# H20 预注册：横截面资金费 carry（crypto 永续，市场中性，含资金费现金流）

> 预注册日期：2026-07-09。**判据在跑回测前锁死，不挪门。**
> 来由：H17 四格对照的一等信息——资金费符号的**相对**信息在两段、两种趋势态下 4/4 一致
> （~+0.4–1.1%/3d/笔），但绝对收益被 regime 支配。本 H 用横截面多空把 regime 对冲掉，
> 并把 H17 没算的**资金费收付现金流**计入收益（空正费率名收费率、多负费率名也收费率，
> 两腿都在收 carry）。这是 19 个 H 里最强的未测线索的正式检验。

## 假设

每周按当期资金费率横截面排序：**做多资金费最负的 6 个名、做空最正的 6 个名**（等权、
等名义、市场中性），持有 7 天。总收益 = 价格价差收益 + 资金费净收入 − 成本，期望为正。

- **经济理由**：资金费是拥挤度的付费价格——极负费率 = 空头拥挤付费（挤压燃料），
  极正 = 多头拥挤。横截面对冲剔除大盘 beta（杀掉 H1-H17 的 regime 命门）；
  资金费现金流本身是确定性的 carry 收入（持有期内两腿同时向我方支付）。
- **已知风险（先写下）**：空高费率名 = 空正在被拉盘的名，短挤压尾部风险大；
  周度再平衡 + 6 名分散是唯一的缓释，不做额外风控（保持假设简单）。

## 数据（已在库，2026-07-09 核验）

- **资金费**：`funding_rate_1d`（Coinalyze daily，Binance 永续），**23 标的 × 1825 天**
  （2021-07-11 → 今），ts = 桶收盘（无 lookahead）。**单位 = percent/8h 结算**（BTC 均值
  0.007、极值 ±0.09/-1.09 与典型 8h 费率量级吻合），值 = 当日**最后一次**结算费率（close）。
- **价格**：`price` 同 23 标的（2021-07-11 起，Coinalyze 日线深史 + 近期 1h 混合密度；
  一律按时间取值 asof/tolerance，不做行索引步进）。
- **资金费累计的近似（锁定并如实声明）**：日累计 ≈ 当日 close 费率 × 3 次结算
  （`3 × f/100`）。这是用日线数据能做到的最好近似；它假设当日三次结算费率相近，
  有采样误差但无方向性偏差。

## 组合构造（锁定）

- **再平衡格点**：每 7 天，锚 = **2021-07-19 00:00 UTC**（数据起点后第一个周一），
  t_k = 锚 + 7k 天，直到 t_k + 7d 有出场价为止。
- **每个 t**：对每个标的取 f = asof(funding, t)（新鲜度 ≤ 2 天，否则该标的本周无效）、
  进场价 = t 后 ≤1 天内第一个价、出场价 = t+7d 后 ≤1.5 天内第一个价；三者齐备才有效。
  有效标的 < 16 → 跳过该周（不算样本）。
- **腿**：按 f 升序，**最负 6 名 long / 最正 6 名 short**（固定名数，不做百分位）。
- **周收益（价差口径，2 单位名义）**：
  `spread = [mean_L(price_ret) − mean_S(price_ret)] + [mean_L(carry_L) + mean_S(carry_S)] − 0.0028`
  其中 carry_L = −Σ_{d∈(t,t+7]} 3·f_d/100（long 在费率为负时收钱）、
  carry_S = +Σ 3·f_d/100（short 在费率为正时收钱）；
  成本 = 每腿每周全换手往返 14bps × 2 腿 = **28bps/周**（保守：不建模腿间重叠留仓）。
- 周度不重叠，无需去重。

## 切分与判据（锁死）

数据只有 2021-07 起 → 切分：**in-sample < 2025-01-01 ≤ holdout**（≈181 周 / 79 周，
与 H17 同界）。裁决在 in-sample 上判，holdout 是 make-or-break。

| # | 判据 |
|---|---|
| ① | in-sample 有效周 N ≥ 100 |
| ② | in-sample 周均 spread > 0 且 bootstrap 95% CI 下限 > 0 |
| ③ | in-sample 周均 > **随机分腿零分布** 97.5 上限（每次抽样：同一批周、同周的有效标的里随机抽 6+6 不重叠名，同一公式含 carry 与成本；2000 次全序列均值的分布）——直接检验"按费率排序"是否优于"随机挑 6v6"，carry 与成本对称计入 |
| ④ | in-sample 周 >0 占比 > 50% |
| ⑤ | holdout 有效周 ≥ 20 且周均 > 0（make-or-break） |

全过 → 有戏，进 Phase 4 前向；任一 FAIL → **KILLED**，照实记 research-log。

## 多重检验声明与已知偏差

- 单一构造：腿数 6、持有 7d、freshness/tolerance 均一次锁定，不扫参。
- **幸存者偏差（方向已想清）**：universe = 今天仍在的 23 名。被拉爆后退市的名缺席
  **压低空腿利润**（空它们本会大赚）→ 偏差方向**不利于本假设** = 保守，可接受。
- 资金费 ×3 近似见上；若裁决处在边缘（差一丝过/不过），此近似不足以翻案——
  边缘即按 FAIL 处理（判据字面执行）。
