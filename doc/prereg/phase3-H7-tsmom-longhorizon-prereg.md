# Phase 3 预注册：H7 — 时间序列动量（TSMOM）长 horizon，检验成本地板能否被跨过

> 预注册：判据/信号/切分跑前写定。写定日期：2026-06-14。
> 来由：H1-H6 六连 KILLED，核心诊断="干净信号存在但幅度 < 14bps 成本地板"（H6：IC -0.05 但毛收益≈0）。
> H7 检验唯一未试的破局维度——**拉长 horizon**：固定 14bps 成本不随持有变长，而 7d 移动幅度远大于 4h，
> 同样的方向性 IC 在长持有上累积成更大移动 → 成本占比下降 → 也许净期望翻正。

---

## A. 假设（可证伪）

**过去 7d 收益为正（负）的标的，未来 7d 倾向继续上涨（下跌）；按该方向持有，扣 14bps 后净期望为正。**

- 经济理由：time-series momentum 是跨资产、跨市场记录最稳的异象之一（趋势在周/月尺度持续）。
  且长持有把固定往返成本摊薄——直接针对"成本地板"诊断。
- 反面（净 ≤0）= 即便拉长 horizon 也跨不过成本/趋势不持续 → 成本地板诊断在长 horizon 上同样成立，
  这本身是对"无简单 edge"存在性结论的进一步加固。

---

## B. 信号（精确、机械、锁定，**禁止调参**）

- 在每个小时 t（去重叠后），计算过去 L 的收益 `r_L = price(t)/price(t−L) − 1`（point-in-time，只用 ≤t）。
- **方向 d = sign(r_L)**：r_L>0 → long，<0 → short。**sign-only，不加幅度阈值**（最不武断、最纯的 TSMOM）。
- **主参数：L = 7d（lookback）**。需 t−L 处有价（容差 90min），否则跳过。
- 去重叠 = 持有期（样本不重叠）。

---

## C. PnL / horizon

- 进场 t 后第一根 1h bar，出场 = 进场 + H。**主 H = 7d**（= lookback）；H=1d/3d 仅记录（探索，不进裁决）。
- 净方向 PnL = `(ret if long else −ret) − COST`，COST=0.0014。

---

## D. universe

- 主：18 小盘篮子。对照：BTC/ETH/SOL/BNB/ZEC。

---

## E. 裁决判据（锁死，①必过 + ②③④⑤；在主 universe=小盘、主 H=7d 上）

1. `|S| ≥ 40`。
2. `mean(pnl_S) > 0` 且 bootstrap 单边 95% CI 下限 > 0。
3. `mean(pnl_S) > 随机择时零分布上限`。
4. 命中率 > 50%（注：动量靠偏度，④偏不利，但锁死沿用；真正看②③⑤）。
5. ≥60% 标的 mean(pnl) 为正。

→ 全过 = **首个扣费后为正的候选 + 成本地板可被长 horizon 跨过** → Phase 4 前向 OOS（make-or-break）。
→ ②不过 = 长 horizon 也跨不过成本地板 → H7 KILLED，"无简单 edge"存在性结论再加固一层。

## F. 防自欺

1. 主参数 L=H=7d 跑前锁死；1d/3d 仅记录，不据其改判（防多重检验/择优）。
2. sign-only 无幅度阈值，杜绝"扫阈值找显著"。
3. price 干净（point-in-time）；~183d 单 regime → 若②过，真确认必须前向 OOS。
4. 7d 持有样本数天然少（dedup 7d → ~26/标的），靠 18 小盘并池补功效；若 |S|<40 标"功效不足"不下结论。
