# Phase 0 预注册：H5 — 突破延续（time-series 动量）

> 预注册：判据/信号/切分在**任何回测前**写定，事后不改。写定日期：2026-06-14。
> 状态：**待测**（零新数据，只用已有 price ~180d+）。前置 H1/H3/H4 全 KILLED（fade/反转家族死，见 research-log.md）。

---

## A. 为什么是这个 H（离开反转家族）

H1（funding 反转）、H3（级联 fade）、H4（级联×OI 条件 fade）**三连高功效负结果**——
"极端→回归"的母题在主流永续、扣成本后稳健地死了。**H5 第一次测它的对立面：趋势延续（动量）。**

- 这是**从未测过的家族**（前三个都是反转变体）。
- H3/H4 的数据本身指向：级联后价格**轻微继续同向**——动量是被自己的负结果点名的方向。
- 学术与业界对加密 **time-series momentum** 有强先验（趋势在多个时间尺度上持续）。
- **零新数据**：只用 price（已有 ~180d+），立刻能跑。
- **成本教训**：前三个 H 在 +4h 上被 14bps 吃亏。H5 用 **+24h** 持有摊薄成本（24h 内主流币常动 2–4%，14bps 占比小）。

---

## B. 假设（可证伪，方向中性对称）

**当价格突破近端区间（创 W 小时新高/新低）时，趋势会延续：沿突破方向持有数小时，净收益为正。**

- 创 48h 新高 → 上行趋势确认 → **做多**。
- 创 48h 新低 → 下行趋势确认 → **做空**。
- 反面（若突破后回落 = 假突破/反转占主导）= H5 死，且与 H1/H3/H4 合起来说明"反转、动量都不行 → 简单价格信号在主流永续上无 edge"。

---

## C. 信号定义（精确、机械、全部锁定，跑前不调）

在每个有 price 的小时 t：
1. **突破窗** W = 48h。取 t 之前（严格 <t）落在 [t−W, t) 的 price 子序列 prior。
2. 需 prior **bar 数 ≥ 24** 且回看跨度 ≥ 0.8·W（早期历史不足不出信号，无未来函数）。
3. `price(t) > max(prior)` → 新高 → d=long；`price(t) < min(prior)` → 新低 → d=short；否则不触发。
4. **去重叠** = **24h**（= 持有期，保证相邻样本不重叠、近独立；突破成簇）。

---

## D. 前向收益 / PnL

- 进场：t 之后第一根 1h bar；出场：进场 +24h（主），+12h/+48h 仅记录。
- 净方向 PnL：`(ret if d==long else −ret) − COST`，COST=0.0014（往返 14bps）。
- 风险调整 `pnl/atr_pct_1h(t)` 仅次要。

## E. 样本 / 切分

## F. 基线

- **随机择时零分布**：保留触发集方向 mix，随机择时 bootstrap 均值零分布（复用 `_mixed_null_upper`）。
- **零基线**：方向性策略，真 edge 必须净期望 > 0。

---

## G. 裁决判据（跑前锁死；①必过 + ②③④⑤）

设主 horizon +24h、去重叠 24h 后的触发集 S：
1. `|S| ≥ 40`（否则功效不足，去前向积累）。
2. `mean(pnl_S) > 0` 且 bootstrap 单边 95% CI 下限 > 0。
3. `mean(pnl_S) > 随机择时零分布上限`。
4. 命中率 > 50%。
5. ≥3/5 标的 mean(pnl) 为正。

→ 全过 = **有戏** → Phase 4 前向确认。

## G'. 杀掉

- `|S|≥40` 但 ②不过 → H5 无 edge，存档。
- `mean(pnl_S)` 显著为负（突破后回落）→ 假突破主导，记反向线索。
- `|S|<40` → 功效不足，**不在突破窗/horizon 上反复换参找显著**。

---

## H. 必须控制的混淆

1. 无未来函数：突破只比 t 之前的 prior；前向收益只用 >t；atr 用进场时已知。
2. 去重叠 24h（= 持有期）保证样本不重叠。
3. 单一主判据 = 主 horizon +24h + W=48h；其余 horizon / 风险调整 = 探索，不进裁决（防多重检验）。
4. universe 固定（BTC/ETH/SOL/BNB/ZEC）；阈值（48h/24h/24bars/+24h）锁死，禁止事后调参。
5. regime：~180d 单一市况，且已是第 4 个 H 复用 → 前向确认是硬约束，不是可选。
