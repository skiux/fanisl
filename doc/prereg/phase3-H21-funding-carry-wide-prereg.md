# H21 预注册：宽 universe 资金费 carry（真实结算 + PIT universe + 真实换手成本）

> 预注册日期：2026-07-09。**判据在跑回测前锁死，不挪门。**
> H20（23 名幸存 universe、日线近似 carry、全换手保守成本）KILLED 的三个死因逐一对症：
> ①功效（135 周 × 巨方差）→ 历史加深至 2020-02 + universe 扩到 147 名（周池更宽，
> 腿的极端更极端）；②成本模型（28bps/周全换手）→ 实测换手 × maker 成本（H20 腿换手
> 实测 ~0.52/腿/周）；③carry ×3 近似 → bulk 逐次结算精确累计。
> **预先声明**：若功效与 universe 加宽后 ③（选择力 vs 随机分腿）仍不过，则资金费
> 横截面选择在免费数据可及范围内正式出局，不再有"参数没调好"的借口。

## 假设

同 H20 机制：做多资金费最负 6 名 / 做空最正 6 名（等权、市场中性、7 天再平衡），
总收益 = 价差 + 两腿资金费净现金流 − 真实换手成本，期望为正。

## 数据（2026-07-09 实地核验）

- **来源**：`data.binance.vision` bulk 月度档（**API 被 451，bulk CDN 实测可达**）。
  - `fundingRate`：逐次结算（8h 一行），`last_funding_rate` 为 **fraction**（BTC 2020-01
    实测 -0.00012 量级），ts=结算时刻 → `um_funding_8h`。**carry 不再 ×3 近似**。
  - `klines 1d`：日线收盘，ts=open+24h 收盘戳 → `um_close_1d`。
- **Universe（锁定规则）**：资金费历史**起点 ≤ 2021-12** 的全部 USDT-M 永续 = **147 个符号**，
  含退市名（LUNA 2021-01→2022-05、SRM 等）——**修掉 H20 的幸存者偏差**：被拉爆/退市的
  名以其真实存续期参与，PIT 成员资格由"该周有数据"天然给出。
  排除 2022+ 新上市（SUI/SEI/TIA 等）：机械规则的代价，如实声明，不因结果回头改。
- **PIT 成员资格（每周 t）**：资金费历史 ≥90 天（成熟度）、最新结算 ≤2 天（新鲜）、
  进场价 t 后 ≤1 天、出场价 t+7d 后 ≤1.5 天，四者齐备。有效名 < 16 → 跳过该周。

## 构造（除声明处外与 H20 逐字一致）

- 再平衡格点：每 7 天，锚 = **2020-02-03 00:00 UTC**（bulk 资金费起始月后第一个周一）。
- 信号：t 时刻最近一次**已结算**费率；按其升序取最负 6 名 long / 最正 6 名 short。
- carry：(t, t+7d] 内**逐次结算费率求和**（fraction 直接累加）；long 收 −Σf、short 收 +Σf。
- **成本（主判据口径，锁定）**：按**实际换手边数**计费，maker 单边 3bps：
  - 每周成本 = 交易边数 × 0.0003；换腿一个名 = 2 边（平旧 1 边 + 开新 1 边）；
    首周建仓 = 12 边；期末清算不计（213+ 周下可忽略，声明）。
  - H20 实测腿换手 ~0.52/腿/周 → 预期周成本 ~6-7bps，carry 现金流 ~20bps/周：
    **盈亏平衡算术先行**（这是本 H 立项依据，写在跑之前）。
  - 探索报告（不判）：taker 单边 7bps 的同型成本。
- ③ 零分布：随机 6/6 分腿（同周同池），**成本用策略当周的实际成本**（不用随机腿自己的
  换手——随机腿每周全换会虚增其成本、放水 ③；同担成本才是干净的"选择力"检验）。

## 切分与判据（锁死）

按 t 切分：**in-sample < 2025-01-01 ≤ holdout**（预期 ~230+ / ~79 周）。

| # | 判据 |
|---|---|
| ① | in-sample 有效周 N ≥ 100 |
| ② | in-sample 周均 spread > 0 且 bootstrap 95% CI 下限 > 0 |
| ③ | in-sample 周均 > 随机分腿零分布 97.5 上限（2000 次，同池同成本） |
| ④ | in-sample 周 >0 占比 > 50% |
| ⑤ | holdout 有效周 ≥ 20 且周均 > 0（make-or-break） |

全过 → 有戏，进 Phase 4 前向；任一 FAIL → **KILLED**，照实记 research-log。
