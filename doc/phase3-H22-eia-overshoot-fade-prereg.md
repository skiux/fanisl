# H22 预注册：EIA 发布过冲的盘中回归（fade surprise，M1 粒度）

> 预注册日期：2026-07-09。**判据在跑回测前锁死，不挪门。**

## 线索来源的诚实披露（先说清，再立 H）

本假设**形成于看过 H19 全样本结果之后**：H19（顺 surprise，+8 交易小时）三段、三 horizon
一致为负（IS -0.31%/HO -0.44%/事件），其镜像算术（fade = +净差 − 2×成本）IS +0.11%、
HO +0.24%。因此 H22 的 holdout 段（≥2019）**不是完全未知的**——其符号已被 H19 的探索
间接看过一次。评价上如实降级：即使全判据 PASS，也只算"强候选"，**必须过 Phase 4 纸面
前向验证**（评测台 playbook candidate）才有下一步；判据本身不因此放松。
与 H19 的可比性靠"最小差异"保证：surprise/假期规则/切分逐字复用，仅改方向与执行粒度。

## 假设

EIA 库存 surprise 的**发布后初始反应是过冲**：发布 5 分钟后**反着 surprise 方向**进场
（超预期累库 → long，超预期去库 → short），持有至当日尾盘，捕获盘中均值回归。

- **经济理由**：定时发布瞬间的流动性真空 + 止损/追单流把价格推过头（H19 证明顺向
  进场在其后数小时一致亏钱 = 回归的存在性）；回归的对手盘是慢钱的重新定价。
  fade 方向由**基本面 surprise 锚定**（不是纯价格反转）：过冲相对的是 surprise 应有的
  合理重定价幅度。

## 数据（2026-07-09 实地核验）

- surprise / 事件 / 假期顺延：逐字复用 h18（build_events/seasonal_z，|z|≥1）与 h19
  （adjusted_publish 联邦假日规则）。
- **价格（新）**：OANDA `WTICO_USD` **M1** mid，实测 2008-06/2012/2019 在 EIA 时段都有
  分钟 bar。只回填**事件窗**（发布−30min → 发布+8h，每事件一页），`metric='price_1m'`
  （稀疏事件窗序列，不作连续序列使用，入库 ts=bar 收盘）。

## 执行（锁定）

- **进场**：调整后发布时刻 **+5 分钟**之后的第一根 M1 收盘（等初始尖峰与点差峰过去）；
  进场 bar 收盘距“发布+5min”超过 15 分钟（数据洞）→ 丢弃该事件。
- **方向**：z > 0（超预期累库，bearish）→ **long**；z < 0 → **short**（= fade surprise）。
- **出场**：进场 +6 小时后的第一根 M1 收盘（容差 30min；≈ 美股收盘后、期货结算前）。
  探索报告（不判）：+2h、+24h（跨夜）。
- **成本**：往返 **12bps**（CFD 常态点差 3-5bps + 发布后 5min 残余放大的保守加成）；
  **敏感性并报（不判）：20bps**。若裁决在 12/20bps 之间翻转，按保守口径写结论边界。
- 周度事件、持有 ≤6h，无重叠。

## 切分与判据（锁死）

按调整后发布 ts 切分：**in-sample 2008~<2019 ≤ holdout**（与 H18/H19 同界）。

| # | 判据 |
|---|---|
| ① | in-sample 触发 N ≥ 100 |
| ② | in-sample 净期望 > 0 且 bootstrap 95% CI 下限 > 0 |
| ③ | in-sample 净期望 > 随机符号零分布 97.5 上限（同批事件进场时刻掷硬币，同成本） |
| ④ | in-sample 命中率 > 50% |
| ⑤ | holdout N ≥ 20 且净期望 > 0（make-or-break） |

全过 → **强候选**（非 edge）：注册进 playbook（status=candidate）跑纸面前向，
先验以 holdout 段为准；任一 FAIL → **KILLED**，EIA 链（H18/H19/H22）整体收档。

## 多重检验声明

单一方向翻转（fade）、单一进场延迟（+5min）、单一主 horizon（+6h）、阈值 |z|≥1 继承
不改。这是 EIA surprise 链的第三次也是**最后一次**检验（顺向日线/顺向盘中/反向盘中
各一次）；再 FAIL 不做第四版。+2h/+24h 与 20bps 口径只作探索，不据其 claim。
